# Image Format Converter

Python desktop application for converting PNG/JPG images into TIFF, BMP, PDF and PSD.

## Features

- PNG, JPG and JPEG input
- TIFF output
- BMP output
- PDF output
- PSD output
- Multiple image selection
- Batch conversion
- Image preview
- Output folder selection
- Duplicate file protection
- Windows GUI

## Run Project

```bash
pip install -r requirements.txt
python main.py
